The one thing to watch: migration 095

EmDash 1.5's migration 095 rescopes plugin storage unique indexes. If a database has any, the old Worker can recreate the old constraint while the new one migrates, so EmDash asks for a maintenance window. Staging had none and migrated cleanly (092–097). Production needs the same read before you promote; auto mode won't let me read production, so I'll ask you to switch it off for that one step.
