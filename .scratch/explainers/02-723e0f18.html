AreaBefore → After

After: packages/ui/src/components/Base.astro owns the sole <link rel="preload" as="image"> tag via preloadImage?: ResponsiveImagePreload (typed via ComponentProps<typeof SharedBase> in both apps), wired across all 7 hero routes.

What to watch

SSR HTML size & markup-only token scans: Each SSR HTML response carries ~14–18 KiB of Brotli-compressed inline CSS for single-RTT first paint. Any test scanning rendered HTML for retired CSS class or variable substrings should strip <style> and <script> blocks first (as verifyNotFound in scripts/seo-fixture.mjs now does) so legacy variables in unmigrated stylesheets don't false-positive against clean page markup.
